## 3. Developer communities (Show HN, r/threejs, three.js forum)

> **Title:** Show HN: Museum scans turned into drone-show formations, flyable in the browser
>
> We're a pre-launch drone light-show company in India. Before our first
> real show, we built the simulator we'll design shows in:
> https://airimation.in/design-your-show
>
> - 56 formations, each from a real 3D model: museum scans (a
>   thousand-year-old Ganesha, Chola bronzes), CC0/CC BY models and
>   symbols we modelled in Blender
> - 100–5,000 drones in one `Points` draw call. The vertex shader morphs
>   between formations; drone-to-slot assignment keeps choreography under
>   8 m/s (real drone speed), and the preview plays at 1.8×
> - Spacing stays physical, so a bigger fleet flies a *bigger* figure
> - Each formation has its own URL; picking one swaps the URL with
>   `history.replaceState` and never reloads the scene
> - React Three Fiber, postprocessing bloom, Next.js
>
> Happy to answer questions about the pipeline (GLB → surface sampling →
> per-drone colour from textures → choreography).

Post on a weekday morning US time. Answer every comment the same day.
